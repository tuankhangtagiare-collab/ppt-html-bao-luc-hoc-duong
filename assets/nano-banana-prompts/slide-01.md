## 📌 Hướng dẫn sử dụng
1. Copy toàn bộ prompt tiếng Anh bên dưới.
2. Dán vào công cụ tạo ảnh AI (**Nano Banana** / Midjourney / Stable Diffusion).
3. Tải ảnh về với định dạng `.webp` hoặc `.png`.
4. Đặt tên file là: `slide-01.webp` (hoặc `slide-01.png`).
5. Lưu file vào thư mục: `assets/images/`.
6. Khởi động lại hoặc làm mới trình duyệt, presentation sẽ tự động hiển thị ảnh này!
